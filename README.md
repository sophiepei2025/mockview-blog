# Mockview Blog

Edmoat blog content for Mockview promotion — university application guides and program listicles, rewritten from source material with Youthfully-branded content removed, CTAs redirected to Mockview/Edmoat, and perishable data (deadlines, rates, tuition) genericized to avoid annual staleness.

## Structure

```
posts/
  guides/       — program-specific application guides (Rotman, Ivey, Waterloo AFM, Queen's Health Sci, UBC Sauder, U of T Engineering)
  listicles/    — "best of" program roundups (CS, business, engineering, health sciences, nursing)
skills/
  edmoat-guide-rewrite-skill.md   — rewrite rules for application-guide content
  blog-image-workflow.md          — image production workflow (stat cards + AI illustrations)
```

Image placeholders in each post are marked as `<!-- [IMAGE: type | description | alt] -->` — see `skills/blog-image-workflow.md` for how to turn these into real assets.

`EDMOAT_CTA_LINK` and `EDMOAT_CONSULTING_LINK` are placeholders throughout — replace with real URLs before publishing.
