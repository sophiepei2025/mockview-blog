# Edmoat 申请指南类文章改写 Skill

适用范围：Program应用指南类文章（Rotman、Western Ivey、Waterloo AFM、Queens健康科学、UofT工程、UBC Sauder 这类，区别于"Best-of Listicle"——listicle已有单独规则，见 edmoat-blog-skill 记忆文件）。

---

## 一、直接删除类（Youthfully专属IP/资产，不能保留任何形式）

| 内容 | 处理方式 |
|---|---|
| "Narrative Communication Approach™" 及相关方法论描述 | 整段删除，essay/interview写作建议部分改写成更通用、不依赖专属框架名的建议 |
| "Youth Coach™"具体主张（"教练都是校友"、"帮助过数百名学生"） | 删除，不用捏造的Edmoat等效数字替代 |
| 链接到 youthfully.com 的资源页（Self-Awareness/Goal-Setting/Narrative Communication Skills Guides等） | 删除引用；如果Edmoat有等效资源页，换成对应链接，没有就直接去掉这句 |
| "Youthfully Insider" 视频提及/embed | 删除 |
| 第三方图片credit链接（image credit 指向学校官网等） | 按上次定的配图工作流处理，换成Edmoat自己生产的数据卡片/插画 |

## 二、泛化处理类（易过期信息，不写死具体值）

| 原文写法 | 改写原则 |
|---|---|
| 具体deadline日期（如"February 13, 2024 at 11:59pm EST"） | 改成"deadline通常在每年X月左右，具体以官网/OUAC公布为准"这类相对表述，不写死年份日期；正文避免"2025/2026"这种申请周期年份标签，改用"当前申请周期"或直接省略年份 |
| 具体录取率/供分（如"7%"、"92%平均分"） | 直接去掉数字，改写成定性描述（如"这是一个竞争激烈的项目，录取门槛逐年可能有变化，建议直接查看学校官网的最新数据"），不做估算替代 |
| 具体学费金额 | 同上，去掉数字，指向官网 |
| Table of Contents 里出现的年份标签 | 去掉年份，只保留内容结构描述 |

## 三、场景判断类替换（CTA逻辑）

不是全文统一替换成一个CTA，要按段落场景判断：

- **面试/口语/video interview/trait assessment 相关段落** → CTA指向 Mockview（"这类面试题练习，正是Mockview这类工具存在的意义"）
- **Essay写作/申请策略/整体规划类"找人帮忙"的段落** → 改成通用的Edmoat咨询CTA（不复制Youthfully的"1对1教练"话术强度，只做克制的、事实性的服务提及，不做"我们的教练是校友"这类无法核实的主张）
- 同一篇文章里，两种CTA都可能出现，但各自只在真正相关的场景触发，不要每个小节都插一次

## 四、保留类（事实层，跟品牌无关，直接照抄或略作精简）

- 申请流程本身的客观事实：OUAC是什么、有哪些申请通道（101/105/国际申请）、Supplemental Application的结构（几篇essay、字数限制、几道video题）——这些是公开、官方的申请机制说明，不属于Youthfully的IP
- 项目结构介绍：课程设置、AEO/co-op这类项目机制、职业出口方向的**定性**描述（保留"学生进入投行/咨询行业"这类描述，去掉"98%就业率"这类具体数字）

## 五、去AI味 + SEO（沿用listicle已定规则）

- 加粗只标真正的专有名词，不做关键词堆砌式加粗
- 删除填充式过渡句（"Trust us"、"Needless to say"类）
- 每篇的H2/H3保留"学校名+项目名+关键词"结构，对SEO友好
- 数据卡片/institution-callout/program-badge视觉组件沿用上次定的规则，适用于本类文章里的"项目结构""考核维度"等信息

## 六、处理流程（每篇文章走一遍）

1. 通读全文，标出：① Youthfully专属资产段落 ② 具体数字/日期 ③ CTA触发点
2. 按以上规则逐条处理
3. 去AI味重写语言
4. 标记配图占位符（沿用已有的 `<!-- [IMAGE: type | 内容 | alt] -->` 格式）
5. 输出最终Edmoat版本
